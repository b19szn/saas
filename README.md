# PulseFlow – Modern SaaS Landing Page (HTML/CSS/JS)

A production-ready, responsive SaaS landing page featuring:
- Hero section with high-contrast CTAs
- Feature Bento Grid (4 key features)
- Pricing section with Monthly / Yearly toggle
- Responsive Contact form with basic validation
- Dark, glassy, high-end aesthetic and smooth micro-interactions

Prerequisites
- A modern browser (Chrome/Edge/Firefox/Safari)

How to run locally (no build steps)
1. Create a folder for the project.
2. Save the following files inside that folder:
   - index.html
   - styles.css
   - app.js
3. Open index.html in your browser (double-click or right-click -> Open with -> Browser).

Project structure
- index.html: Markup and structure of the landing page
- styles.css: All styles, tokens, layout, responsive rules
- app.js: Interactive behaviors (pricing toggle, smooth scrolling, contact form)

Tips for customization
- Change brand colors by editing CSS variables in styles.css (e.g., --brand-1, --brand-2).
- Update hero copy in index.html to reflect your product narrative.
- Modify pricing data attributes in index.html to reflect your pricing strategy.
- Extend the feature grid by duplicating feature-card blocks in index.html.
- Expand the contact form handling in app.js as needed (e.g., real API submission).

Notes
- The project is designed to run directly in the browser with no server required.
- All assets are embedded in code (SVG icons and gradient visuals), no external image dependencies.
